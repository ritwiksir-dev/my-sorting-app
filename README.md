My Sorting App

A simple, fast, and user-friendly web application for sorting names, words, numbers, and mixed lists.

Features

- Sort words and names from A–Z or Z–A
- Sort numbers from smallest to largest or largest to smallest
- Choose between Auto, Words, and Numbers sorting
- Supports mixed text and numerical entries
- Handles numbered/serialised lists
- Ignores leading serial numbers while sorting
- Automatically renumbers sorted lists
- Option to keep the first line as a heading
- Remove duplicate entries
- Copy sorted results with one click
- Works on mobile phones, tablets, and computers
- No login or installation required
- All sorting is performed locally in the browser

How to Use

1. Paste or type your list into the Input box.
2. Select Auto, Words, or Numbers.
3. Choose the required sorting direction.
4. If your list has a heading, select First line is a heading.
5. Copy the sorted result using Copy Result.

Privacy

The app runs entirely in your web browser. The information entered into the app is not uploaded to or stored on a server.

Technology

Built as a lightweight standalone web application using HTML, CSS, and JavaScript.
